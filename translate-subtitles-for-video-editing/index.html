How it works

  1. Export your sequence's captions as an .srt or .vtt from your editor.
  2. Drop the file in, choose your target language, and translate.
  3. Edit any awkward line inline, then export .srt or .vtt.
  4. Re-import the translated file into Premiere, DaVinci, Final Cut, or CapCut.

Frequently asked questions

Which editors does this work with?

Any editor that imports .srt or .vtt, Premiere Pro, DaVinci Resolve, Final Cut Pro, CapCut, Kdenlive, and more. The format is universal.

Are my timecodes kept?

Yes, exactly. Only the dialogue text is translated; every timestamp is preserved, so the file re-imports perfectly in sync.

Can I translate a whole season of files?

The translator works on one file at a time, up to 200 lines per file. There is no multi-file batch mode.
