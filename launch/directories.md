## Reusable assets (fill once, paste everywhere)

- **Tool name:** SubCaptions
- **URL:** https://subcaptions.com
- **One-liner:** Caption any YouTube video right on top of the video, in your browser, then translate into 50+ languages.
- **Category:** Video / Subtitles / Creator Tools / Productivity
- **Pricing model:** Freemium (captioning free; Pro from $9/mo for translation volume and long videos)
- **Logo:** 🎬 mark, 512x512 PNG on the light gradient background.
- **Short description (about 50 words):**
  SubCaptions is a free, no-signup web tool for subtitling YouTube videos. Paste a link and build captions on top of the video: play, mark each line's in and out point with a keystroke, type it, and see it on screen instantly. Export .srt or .vtt, then translate into 50+ languages in one click.
- **Long description (about 100 words):**
  SubCaptions is a browser-based subtitle editor that puts the captions on the video. Paste any YouTube link, press play, and mark when each line starts and ends with the S and E keys while you type. Each caption renders on the real video the moment you save it, so timing is never a guess. Your work is saved locally and never uploaded. Export standard .srt or .vtt for YouTube, Premiere, DaVinci Resolve, Final Cut, or CapCut. When you're done, translate the whole set into 50+ languages in one click and download each. Captioning is free with no signup or watermark.

## AlternativeTo (alternativeto.net)
- This is positioning, not just a listing. Add SubCaptions as an alternative to tools people already search for:
  - **Subtitle Edit / Aegisub** (desktop) -> position as "browser-based, captions on the video, nothing to install"
  - **Kapwing / Veed.io / Subtitle Cat** -> position as "no upload, no watermark, captions stay in your browser, type-don't-fix-a-transcript"
  - **YouTube's built-in subtitle editor** -> position as "faster keyboard-first workflow with a live preview and clean .srt export"
- Create the product page, then on each competitor's page click "Suggest as alternative."
- Tag features: `Free`, `No Registration Required`, `Privacy focused`, `Web-based`.
